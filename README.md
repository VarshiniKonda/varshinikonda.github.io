# Sri Varshini Konda — Portfolio

A responsive personal portfolio for showcasing AI, machine learning, and full stack projects.

**Live site:** [https://varshinikonda.github.io](https://varshinikonda.github.io)
**Repository:** [github.com/VarshiniKonda/varshinikonda.github.io](https://github.com/VarshiniKonda/varshinikonda.github.io)

## Features

- Dark-first design with a remembered light/dark theme
- Profile photo stored at `assets/profilepic.svg`
- Responsive layout, mobile navigation, and active-section highlighting
- Animated role text, subtle hero background, and scroll-reveal effects
- Reduced-motion support, keyboard focus styles, and a skip link
- Filterable project cards rendered from an editable JavaScript array
- Email copy button and a validated contact form ready for Formspree
- SEO metadata, social-sharing cards, and a custom SVG favicon

## Tech stack

- Semantic HTML5
- CSS3 with responsive layouts and CSS custom properties
- Vanilla JavaScript (no frameworks, build step, or package manager)
- Google Fonts: DM Sans, Space Grotesk, and DM Mono

## Deploy on GitHub Pages

1. The public repository **`VarshiniKonda/varshinikonda.github.io`** has been created.
2. Push the site files to the repository's `main` branch.
3. If the included GitHub Actions workflow does not enable Pages automatically, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
4. Add your résumé PDF at `assets/Varshini_Resume.pdf`. Add a screenshot at `assets/screenshot.png` if you want to show one in this README.
5. Check the **Actions** tab for the Pages deployment. Your site will be available at **https://varshinikonda.github.io** when the workflow completes.
